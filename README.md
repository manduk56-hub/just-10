# JUST 10. — 흑요석 10초 챌린지

다이아몬드 곡괭이로 흑요석을 캐며 정확히 10초에 멈추는 타이밍 미니게임입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열고 스페이스바로 시작하세요. 12초가 지나면 자동으로 종료됩니다.

`docs/index.html`은 이미지와 게임 코드를 한 파일에 담은 독립 실행 버전입니다. 파일을 브라우저로 열어도 바로 플레이할 수 있습니다.

## 조작

- 스페이스바 또는 버튼으로 시작하고 멈춥니다.
- 목표는 10.000초이며 ±0.100초 안에 멈추면 성공입니다.
- 6초 이후에는 타이머 숫자가 숨겨져 난이도가 올라갑니다.

Minecraft 텍스처는 [PrismarineJS/minecraft-assets](https://github.com/PrismarineJS/minecraft-assets)에서 가져왔습니다. 이 프로젝트는 Mojang / Microsoft와 무관한 비공식 팬 미니게임입니다.
